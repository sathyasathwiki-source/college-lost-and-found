2. Custom Hash Table — Item Cache

Maps item IDs → item records. Currently caching {{ ht_size }} items. Uses a 128-bucket array with chaining for collision resolution. Average-case lookup: O(1).

{% if ht_size > 0 %}
Hash function: bucket = abs(hash(str(item_id))) % 128
{{ ht_size }} key-value pairs stored across 128 buckets. When two keys map to the same bucket, they are stored as a chain (list) within that bucket — this is called chaining.
