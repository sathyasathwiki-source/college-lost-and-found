About This Project

Campus Lost & Found — FDS Mini-Project, BTech First Year

Project Overview

Campus Lost & Found is a college lost-and-found management system developed as a mini-project for the Fundamentals of Data Structures (FDS) course, BTech First Year — Pune Institute of Computer Technology (PICT).

The system provides a centralized platform for students to report lost belongings, register found items, search records, identify possible matches, and manage returns. It demonstrates fundamental data structures — singly linked list, hash table, and queue — in a real-world application.

Data Structures Used

1. Singly Linked List

Used for the in-memory activity feed — the list of recent item reports shown on the dashboard. New activity is inserted at the head in O(1). The list is trimmed to 20 entries to keep memory bounded.

2. Custom Hash Table

Used as an item cache that maps item IDs to item records. Implemented with a bucket array and chaining for collision resolution. Provides O(1) average-case lookup — much faster than a full database query for items that are frequently accessed (such as on the item details page).

3. Queue (Linked-List based)

Used to manage collection requests in FIFO order. When a student submits a collection request, it is enqueued. Administrators process requests from the front of the queue. Both enqueue and dequeue are O(1).
